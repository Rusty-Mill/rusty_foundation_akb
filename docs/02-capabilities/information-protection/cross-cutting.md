# Cross-cutting qualities

**RM-PROTECTION-XCUT-0001:** Security review covers forged/stripped/foreign labels, metadata-content divergence, downgrade bypass, classifier evasion, encoded/fragmented content, unsupported/encrypted channels, recipient confusion, rights/key misuse, stale/offline policy, alternate capture, provider compromise, audit leakage, and UI spoofing/coercion.

**RM-PROTECTION-XCUT-0002:** Operations bound content/fields/rows/items/recipients, rule/model work, graph depth, bytes expanded/transformed, provider/network calls, memory/storage/CPU/time, concurrent decisions, UI findings, audit volume, and remediation/reconciliation fanout.

**RM-PROTECTION-XCUT-0003:** Performance separates inspection/classification, policy evaluation, user/approval wait, marking/encryption/transformation, channel enforcement, recipient delivery/access, audit, and reconciliation. User think time and provider latency are not abstraction overhead.

**RM-PROTECTION-XCUT-0004:** Accessibility includes localized taxonomy guidance, non-color-only markings, screen-reader label/protection state, keyboard mediation, readable warnings/justification, hostile-content isolation, accessible approval/recovery, and preservation of source/output document accessibility through transformations.

**RM-PROTECTION-XCUT-0005:** Internationalization handles translated label display while stable IDs govern policy; right-to-left and long markings, locale-specific classifiers, character/token segmentation, recipient names, time zones, and jurisdiction are explicit without locale-dependent authority.

**RM-PROTECTION-XCUT-0006:** Observability uses classified schemas and records generations, stages, outcomes, unsupported coverage, latency/resource/freshness, overrides, partial effects, and reconciliation while excluding raw sensitive matches and secrets by default.

**RM-PROTECTION-XCUT-0007:** Multi-tenant isolation covers taxonomies, classifiers, dictionaries, policies, label metadata, keys/rights, findings, recipients, tips, approvals, caches, incidents, audit, and provider/cloud submissions; shared work requires proven equivalent partitions.
