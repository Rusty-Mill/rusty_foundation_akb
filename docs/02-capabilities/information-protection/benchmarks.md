# Benchmarks

**RM-PROTECTION-BENCH-0001:** Classification workloads vary formats/languages/encodings, subject size/field count, match prevalence/location, rule/model/dictionary complexity, manual/recommended/automatic mode, local/cloud provider, encrypted/partial data, cache/freshness, concurrency, and tenant mix.

**RM-PROTECTION-BENCH-0002:** Report time to first/final recommendation or decision, scanned coverage, classifier precision/recall/calibration on declared datasets, throughput, CPU/GPU, memory, I/O/network, allocations, energy, provider cost, false-positive review load, and privacy disclosure.

**RM-PROTECTION-BENCH-0003:** Protection workloads measure marking/layout, metadata updates, encryption/decryption/rekey, rights acquisition/refresh/revocation, recipient/group expansion, transform/validate/publish, storage/network amplification, offline start, and recovery separately.

**RM-PROTECTION-BENCH-0004:** DLP channel trials vary clipboard/file/removable/print/capture/message/upload/cloud/API/AI paths, foreground/background, single/batch/stream sizes, managed/unmanaged identities/devices/apps, recipient counts, warn/justify/approval, offline/provider failure, and concurrency.

**RM-PROTECTION-BENCH-0005:** Measure decision and enforcement latency distributions, UI responsiveness and task completion, block/allow correctness, bytes/items escaped before decision, partial effects, cancellation, policy/provider calls, queue/fairness, audit overhead, reconciliation convergence, and user override/error rates.

**RM-PROTECTION-BENCH-0006:** Adversarial trials measure bounded behavior under obfuscation, fragmentation, nested/encoded data, classifier near misses, label stripping/forgery, stale/offline policy, recipient churn, alternate channels, provider crashes/timeouts, cache invalidation storms, and repeated override attempts.

**RM-PROTECTION-BENCH-0007:** Native/provider comparisons use identical content and labels, policy generations, identities/recipients/channels, classifier databases, protection settings, network/offline state, user steps, coverage, audit, and correctness assertions. Missing enforcement or privacy protections are not scored as speed.
