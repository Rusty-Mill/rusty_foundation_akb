# Activation and association conformance specification

| Area | Required evidence |
|---|---|
| Intent | every kind/verb/target, multi-target order/partial policy, provenance/freshness/interaction, unsupported/extension fields, no shell interpretation |
| Handler/association | registered/eligible/default/recommended/enforced states, role/verb, conflicting/layered policy, install/update/uninstall, stale cache, notification loss |
| File | path versus handle/token/bookmark, read/write/reveal/print, replacement/symlink/cloud/removable/quarantine, executable/script denial, persistent-reference expiry |
| URI | scheme grammar, percent/Unicode/IDNA/control/userinfo/nested/file/custom/web association, secret redaction, high-impact confirmation, browser/app fallback |
| Outgoing | default/ask/exact/recommend modes, foreground/background/headless, chooser cancel, broker deny/restart, batch split/partial, sandbox crossing |
| Incoming | initial/existing/multi-instance routing, startup queue, duplicate/concurrent activation, stale target/authority, focus denial, schema/version, ordinary domain validation |
| Completion | every milestone, cancellation race, app/provider crash, timeout/unknown, retry duplicate policy, readiness/handled acknowledgment absence |
| Cross-cutting | plugin/remote prompt flood, association privacy, accessible chooser/settings/status/recovery, keyboard/screen-reader/focus/localization/bidi |

Fixtures cover files/directories, lossless non-Unicode names, spaces/control/reserved characters, mixed-case/ambiguous extensions and MIME, local/network/cloud/portal/bookmark targets, custom/http/mailto/file and hostile nested URIs, multiple/no/stale handlers, per-user/per-machine/admin associations, new/existing/crashed apps, rapid duplicates, session changes, and restricted/sandboxed/headless environments.

Reports bind OS/desktop/broker/version, caller/handler package identity/provenance, session/sandbox/foreground, intent/target type and synthetic fixture identity, association scope/revision/source, selected mode and interaction, file authority class, URI normalization/version, every milestone/evidence boundary, registration/package generation, and all focus/domain-success/authority nonclaims. Paths, URI payloads, recent/default history, and user application inventories are redacted.
