# Conformance

**RM-COMMS-CONFORMANCE-0001:** Lifecycle suites cover intent/plan/render/attempt/provider/delivery/engagement boundaries, duplicate and ambiguous submission, callback duplication/reorder/gaps/regression, reconciliation, retry/fallback, cancel/expiry, and exact aggregate denominators.

**RM-COMMS-CONFORMANCE-0002:** Recipient/preference suites cover mutable/recycled/shared endpoints, account/device/tenant transitions, dynamic audiences, consent and scoped opt-outs, quiet hours/time zones, frequency races, provider suppressions, mandatory exceptions, and propagation delay.

**RM-COMMS-CONFORMANCE-0003:** Rendering suites cover schema/escaping/injection, all locales/scripts/directions, long/empty/adversarial values, HTML/text/SMS segments/push limits, client/provider transformations, assistive technologies, no-images/high-contrast/dark mode, and safe fallbacks.

**RM-COMMS-CONFORMANCE-0004:** Email suites cover MIME/header/address edge cases, SPF/DKIM/DMARC mappings, relay/DSN/bounce/complaint, unsubscribe authenticity/idempotency, auto-reply loops, tracking proxies/scanners, attachments, and inbound quarantine.

**RM-COMMS-CONFORMANCE-0005:** SMS/push suites cover route/encoding/segments, delivery receipt variance, keywords, number reassignment, token rotation/reinstall, TTL/collapse/order/loss, provider invalidation/throttle, permission/power/background restrictions, encrypted Web Push, and app reconciliation.

**RM-COMMS-CONFORMANCE-0006:** Abuse/security suites cover list bombing/enumeration, compromised tenants/senders/templates, phishing/smishing, malicious URLs/files, forged/replayed webhooks, credential rotation, cross-tenant leaks, excessive cardinality, and emergency/security availability.

**RM-COMMS-CONFORMANCE-0007:** Evidence records fixtures/seeds, intent/audience/preference/template/render/plan/provider generations, endpoint controls, locale/time/policy, network/provider fault schedule, native statuses, normalized outcomes, unknowns, privacy redaction, and artifact digests.
