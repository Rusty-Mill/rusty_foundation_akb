# Benchmarks

**RM-WORKFLOW-BENCH-0001:** Start/command/signal/query/update benchmarks report definition/state/payload/history sizes, cold/warm caches, persistence/replication topology, consistency, concurrency, requests, CPU, allocation, memory, throughput, and p50/p95/p99 commit/visibility latency.

**RM-WORKFLOW-BENCH-0002:** Replay benchmarks report history event/payload/snapshot counts, definition/code/toolchain, cold/warm state, replay throughput/latency, CPU/memory/I/O, cache hit, snapshot verification/fallback, and determinism instrumentation.

**RM-WORKFLOW-BENCH-0003:** Activity/effect benchmarks report queue/dispatch/poll/start/heartbeat/target/result/history phases, workers/concurrency, retries/timeouts/faults, idempotency/fencing cost, backlog/catch-up, amplification, and effect residuals.

**RM-WORKFLOW-BENCH-0004:** Timer/parallel/child benchmarks vary timer cardinality/horizon, due bursts/calendar rules, branches/map size/join type, child depth/fan-out, cancellation, provider failover, scheduling drift, resource usage, and completion latency.

**RM-WORKFLOW-BENCH-0005:** Human-task benchmarks report system queue/list/filter/claim/form/save/submit/decision/fulfillment phases separately from human decision time, task/actor/group cardinality, authorization selectivity, notifications/escalations, offline conflicts, accessibility/privacy overhead, and audit volume.

**RM-WORKFLOW-BENCH-0006:** Migration/recovery benchmarks report active instances/history/state/outstanding work, validation/simulation, quiescence/transform/commit, mixed workers, interrupted migration, backup/restore, projection rebuild, dispatch/timer reconciliation, target verification, recovery time, and data/effect loss bounds.
