# Cross-cutting qualities

**RM-WORKFLOW-XCUT-0001:** Security authenticates every command/signal/task/activity/operator action, passes attenuated authority, reauthorizes delayed effects, fences stale workers, validates payloads, isolates tenants, signs definitions, and prohibits replay from minting authority.

**RM-WORKFLOW-XCUT-0002:** Privacy applies purpose/minimization to history, payloads, search fields, task lists/forms/comments/attachments, operator views, exports, analytics, retention/redaction, human decisions, and external processors while preserving required audit lineage.

**RM-WORKFLOW-XCUT-0003:** Accessibility and internationalization apply to every human task, notification, deadline, escalation, form, decision, error, repair, and status view with adequate time, keyboard/screen-reader support, localized resources/calendars, and non-localized stable identifiers.

**RM-WORKFLOW-XCUT-0004:** Observability correlates instance/run/history/decision/activity/attempt/task/timer/child/effect generations, separates queue/worker/human/target latency, reports replay/migration/revocation residuals, and redacts sensitive payloads and policy.

**RM-WORKFLOW-XCUT-0005:** Async-first operations provide cancellation/deadlines/streaming observation/backpressure; sync completeness covers bounded local validation/query construction but never blocks indefinitely on human, timer, worker, or remote effect completion.

**RM-WORKFLOW-XCUT-0006:** Performance uses event batching, snapshots, indexed projections, sticky/local replay caches, batched task/activity dispatch, bounded histories, and parallelism while preserving deterministic semantics, fencing, authorization, and effect evidence.
