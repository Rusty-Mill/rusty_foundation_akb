# Benchmarks

**RM-AUDIT-BENCH-0001:** Measure producer encode/validation/append-receipt overhead and domain-effect latency impact by event size/schema/class, atomic/outbox mode, durability/protection, batching, concurrency, and pipeline health.

**RM-AUDIT-BENCH-0002:** Measure collect/validate/dedup/sequence/segment/compress/encrypt/sign/anchor/index/export throughput, latency, backlog and recovery by sources, tenants, event rate, cardinality, gaps, and failures.

**RM-AUDIT-BENCH-0003:** Measure point/range/correlation/graph/aggregate/investigation queries, proof verification, reindex, export, report/assessment generation, redaction/tokenization, and hold/retention scans by corpus and authorization complexity.

**RM-AUDIT-BENCH-0004:** Measure storage/network/write/read amplification, segment/proof/index sizes, CPU/memory/allocations, key/provider calls, anchor/export cost, retention-tier transitions, restore/reconcile time, and energy.

**RM-AUDIT-BENCH-0005:** Sustained/adversarial tests report drop/duplicate/gap/late rates, time-to-detect, fail-closed/degraded impact, fairness, query isolation, cardinality bounds, proof coverage, privacy leakage, recovery, and semantic correctness.

**RM-AUDIT-BENCH-0006:** Reports pin event corpus/history digest, schemas/policies/source populations, storage/proof/index/export providers, key/trust/anchor, topology, clock/fault model, warmup, distributions/confidence, costs, completeness scope, and correctness assertions.
