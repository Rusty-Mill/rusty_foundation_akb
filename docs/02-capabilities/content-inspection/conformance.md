# Conformance

**RM-CONTENT-CONFORMANCE-0001:** Identity suites cover registered/unregistered/aliased/deprecated media types and parameters, platform type systems, extensions/globs/user overrides, case/Unicode/hidden/multiple extensions, invalid declarations, missing declarations, and declared/detected mismatch.

**RM-CONTENT-CONFORMANCE-0002:** Detection corpora include exact/near-miss signatures, truncation at every boundary, false positives, offset/length overflow, wrappers, concatenation/trailing overlays, text/binary ambiguity, profile variants, encrypted/opaque data, generated mutations, and provider differential expectations.

**RM-CONTENT-CONFORMANCE-0003:** Polyglot corpora exercise every selected downstream interpretation pair, active content in passive containers, parser-version/configuration differences, extension/declaration conflicts, canonicalization, and transformations that must remove or retain alternate views.

**RM-CONTENT-CONFORMANCE-0004:** Recursive suites cover archives/documents/messages/media/scripts, shared nodes, cycles, external references, missing passwords/keys, depth/node/byte/ratio/provider limits, partial frontier aggregation, ancestry, cancellation, and no network by default.

**RM-CONTENT-CONFORMANCE-0005:** Origin/quarantine histories cross acquisition, copy/move/rename, archive/extraction, mount/sync, IPC, transform, backup/restore, hard links, metadata loss, native external mutation, user/admin override, and policy revocation on Windows, Linux, and macOS.

**RM-CONTENT-CONFORMANCE-0006:** Scanner/reputation suites test every native result, signature/model/provider update, stale/offline/cloud-disabled modes, privacy/region consent, hash/content submission, wrong generation, provider crash/hang/spoof, remediation separation, and no-finding nonclaims.

**RM-CONTENT-CONFORMANCE-0007:** Preview/transform fault injection interrupts every parse/render/decode/font/external-resource/write/validate/publish boundary and verifies sandbox authority, active-content suppression, loss reports, output validation, cache partitioning, cleanup, and source immutability.

**RM-CONTENT-CONFORMANCE-0008:** Reports bind corpus and subject digests, OS/build, filesystem, provider/library/database/model/rule/policy versions, purpose, restrictions, limits, network/disclosure mode, cache state, expected evidence, and every skipped/degraded assertion.
