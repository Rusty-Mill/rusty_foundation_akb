# Benchmarks

**RM-CONTENT-BENCH-0001:** Detection workloads vary format/profile, corpus distribution, size, prefix availability, seek/range/stream source, declarations/extensions, ambiguity/polyglots, rule database, cache state, concurrency, and provider while reporting time to first/final evidence, bytes/ranges read, accuracy by declared corpus labels, CPU, memory, I/O, and energy.

**RM-CONTENT-BENCH-0002:** Recursive inspection varies graph depth/nodes, compression/encoding, embedded/reference density, shared/cyclic nodes, encrypted/unsupported nodes, local/remote sources, findings position, and budgets while measuring frontier coverage, amplification, goodput, tail latency, resource peaks, and fairness.

**RM-CONTENT-BENCH-0003:** Malware/reputation trials separate local engine initialization, signature/model update, cold/warm scan, session correlation, hash reputation, metadata/cloud/content submission, offline/timeout, concurrency, privacy modes, and database freshness with verdict correctness and disclosure accounted.

**RM-CONTENT-BENCH-0004:** Preview/transformation workloads vary pages/frames/duration/resolution, fonts/color/codecs, active/embedded/external content, sandbox startup/reuse, output profile, semantic loss, validation, staging/publication, cancellation, and crash recovery.

**RM-CONTENT-BENCH-0005:** Adversarial trials measure bounded rejection under signature near misses, malformed structures, polyglots, bombs, parser hangs/crashes, external-reference storms, hostile names/UI text, provider outage, cache invalidation storms, and repeated transient failures.

**RM-CONTENT-BENCH-0006:** Native/provider comparisons use identical subjects, purpose, candidate universe, rule/database freshness, restrictions, limits, network/disclosure policy, output validation, and correctness assertions. A broader parser, cloud upload, missing isolation, or weaker coverage is not credited as performance.

**RM-CONTENT-BENCH-0007:** Reports publish hardware, OS/build, filesystem/storage/network, sandbox and provider topology, corpus digests/distribution, provider/library/model/signature/rule/policy generations, cache/warmup, concurrency/resources, repetitions, uncertainty/outliers, telemetry overhead, and monetary/provider costs.
