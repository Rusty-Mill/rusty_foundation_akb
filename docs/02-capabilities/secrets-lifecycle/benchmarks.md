# Benchmarks

**RM-SECRETS-BENCH-0001:** Store/broker benchmarks report provider/protection class, operation and secret-size mix, cold/warm/locked state, local/remote topology, concurrency, requests, CPU, allocation, peak locked/secret memory, throughput, and p50/p95/p99 latency without output-derived measurements.

**RM-SECRETS-BENCH-0002:** Dynamic-credential benchmarks report target/provider/profile, issuance/activation/renewal/revocation phases, lease durations, role/account churn, connection behavior, throttling/faults, target cleanup convergence, request amplification, and residuals.

**RM-SECRETS-BENCH-0003:** Opaque-use benchmarks report exact operation/provider/hardware boundary, algorithm/protocol/input sizes, prompt/quorum time separately, session reuse, concurrency, queueing, cancellation, target latency, CPU/memory, and oracle/security instrumentation overhead.

**RM-SECRETS-BENCH-0004:** Delivery/adoption benchmarks report form, secret/bundle size, dependent count/topology, distribution/write/notification/reload/ready/target-accepted phases, open-handle/cache behavior, propagation, resource cost, and exposure instrumentation.

**RM-SECRETS-BENCH-0005:** Rotation benchmarks report fleet/dependency graph, generations, overlap, issuance and target rate limits, scheduling/jitter, partial faults, successor-use and predecessor-denial distributions, expiry margin, retries, residuals, and emergency compromise mode.

**RM-SECRETS-BENCH-0006:** Recovery/incident benchmarks report corpus/provider/backup topology, detection and containment phases, revoke/rotate fan-out, restore/migration validation, reconciliation, deletion frontiers, operator workflow time separately, and security/privacy/audit overhead.
