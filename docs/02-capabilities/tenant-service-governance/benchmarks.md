# Benchmarks

**RM-TENANT-GOV-BENCH-0001:** Measure tenant provisioning/readiness/suspend/resume/close and placement migration by resource count, isolation tier, cell/shard topology, data volume, external providers, and fault stage.

**RM-TENANT-GOV-BENCH-0002:** Measure entitlement evaluation/cache/invalidation/simulation latency and throughput by rule/dependency depth, offers/overrides, tenants/features, mixed generations, provider lag, and revocation fan-out.

**RM-TENANT-GOV-BENCH-0003:** Measure quota check/reserve/commit/release/reconcile by dimensions, contention/skew, consistency mode, partition, lease distribution, overshoot, fairness, and recovery.

**RM-TENANT-GOV-BENCH-0004:** Measure meter accept/dedup/validate/aggregate/rate/adjust/export and end-to-end availability by event rate, dimensions/cardinality, window, lateness, tiers, precision, tenants, storage, and provider backlog.

**RM-TENANT-GOV-BENCH-0005:** Report latency distributions, goodput, backlog/lag, admission error/overshoot, reconciliation residual, CPU/memory/storage/network, amplification, cardinality, energy, provider calls/cost, recovery, and correctness.

**RM-TENANT-GOV-BENCH-0006:** Reports pin corpus/history digest, topology/isolation, catalog/agreement/policy/meter/quota/rating/provider generations, period/calendar/currency/rounding, faults, warmup, confidence, privacy controls, and semantic assertions; comparisons use equivalent evidence boundaries.
