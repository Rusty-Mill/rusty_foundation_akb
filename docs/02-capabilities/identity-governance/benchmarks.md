# Benchmarks

**RM-IDENTITY-GOV-BENCH-0001:** Snapshot benchmarks report objects, attributes, groups, edges, page size, provider/source topology, consistency mode, bytes, requests, CPU, allocation, peak memory, throughput, and p50/p95/p99 latency.

**RM-IDENTITY-GOV-BENCH-0002:** Change benchmarks report event rate, burst shape, duplicate/reorder/gap rate, checkpoint cost, apply throughput, backlog, source-to-observed convergence, invalidation convergence, and recovery from cursor expiry.

**RM-IDENTITY-GOV-BENCH-0003:** Provisioning benchmarks report create/patch/membership/disable/delete mixes, batch size, concurrency, throttling, conflicts, retries, partial failures, reconciliation passes, request amplification, completion frontier, and residual rate.

**RM-IDENTITY-GOV-BENCH-0004:** Group benchmarks report members/edges/nesting/depth/cycles, dynamic rule complexity and input size, incremental/full evaluation, cache state, unknown inputs, entitlement invalidation, throughput, memory, and tail latency.

**RM-IDENTITY-GOV-BENCH-0005:** Governance benchmarks report campaign/request population, approver graph, workflow complexity, notification and fulfillment queues, decision and revocation convergence, deadline misses, provider faults, and audit volume without benchmarking human judgment as machine latency.

**RM-IDENTITY-GOV-BENCH-0006:** Deprovisioning benchmarks report every selected boundary, fan-out, online/offline providers, session/credential/resource counts, disable-to-deny and full reconciliation distributions, retries, residuals, restoration checks, and security/privacy instrumentation overhead.
