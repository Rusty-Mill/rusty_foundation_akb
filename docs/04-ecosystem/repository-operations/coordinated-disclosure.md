# Coordinated disclosure

**RM-REPOSITORY-DISCLOSURE-0001:** Vulnerability intake offers authenticated private channels plus a public security contact/policy, supported languages/formats, encryption where selected, safe-harbor expectations, response targets, scope, and emergency route.

**RM-REPOSITORY-DISCLOSURE-0002:** Reports receive stable confidential identity, receipt, reporter/contact preference, affected target claims, reproduction/evidence, disclosure constraints, sensitivity, duplicates, and access-controlled audit. Uploaded artifacts are hostile and isolated.

**RM-REPOSITORY-DISCLOSURE-0003:** Triage distinguishes vulnerability, hardening, misuse, dependency/upstream, compromised release, leaked credential/key, active exploitation, availability abuse, privacy, and non-security defect, with rationale and escalation.

**RM-REPOSITORY-DISCLOSURE-0004:** Case roles separate reporter liaison, triage, technical investigation, fix owner, release owner, advisory/CVE coordination, communications, legal/privacy, and incident command where required.

**RM-REPOSITORY-DISCLOSURE-0005:** Embargo scope and target date are explicit, least-privilege, reviewable, and adjusted with recorded rationale. It never prevents immediate bounded action needed to protect users under active exploitation.

**RM-REPOSITORY-DISCLOSURE-0006:** Fix development uses private branches/artifact storage and avoids public CI/log/package/dependency metadata leaks. Candidate fixes undergo security regression, conformance, packaging/signing, and deployment/rollback review before coordinated release.

**RM-REPOSITORY-DISCLOSURE-0007:** External coordination tracks upstream/downstream distributors, affected dependents, CVE/CNA/advisory providers, infrastructure operators, and disclosure time zones without disclosing reporter/private evidence beyond need.

**RM-REPOSITORY-DISCLOSURE-0008:** Publication synchronizes fixed artifacts or mitigations, repository metadata, advisory revision, credits, support communications, rollout/monitoring, and post-embargo evidence. A missed deadline produces explicit status, not silent abandonment.

**RM-REPOSITORY-DISCLOSURE-0009:** Case closure records affected/fixed truth, distribution coverage, residual unsupported versions, lessons/actions, reporter notification, retention/redaction, and whether an incident/postmortem is required.
