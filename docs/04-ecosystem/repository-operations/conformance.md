# Repository-operations conformance

Every report binds repository/provider/profile versions, namespace/package/channel, authority and trust generations, workflow/source, fixtures, region/mirrors, clocks/network, and result evidence.

**RM-REPOSITORY-CONFORMANCE-0001:** Authority tests cover every role/scope, human/workload separation, expired/revoked credentials, approval substitution, quorum loss, owner transfer/succession, dormant/compromised accounts, break glass, and audit nonrepudiation without secret disclosure.

**RM-REPOSITORY-CONFORMANCE-0002:** Publication tests cover complete candidates and missing/mismatched source/artifact/signature/provenance/SBOM/license/conformance/advisory evidence, duplicate/reserved versions, namespace confusion, partial uploads, concurrent publication, timeout/retry, metadata-signing failure, and visibility reconciliation.

**RM-REPOSITORY-CONFORMANCE-0003:** Immutability tests attempt asset/tag/version/digest replacement, deletion/reuse, repository resurrection, provider-generated archive drift, referrer mutation races, and correction without a new version/revision.

**RM-REPOSITORY-CONFORMANCE-0004:** Channel tests cover same-digest promotion, prohibited rebuild/repack, stale gates, demotion/hold/yank/deprecation/revocation differences, mutable tag resolution, monotonic metadata, policy rollback, and multi-channel concurrency.

**RM-REPOSITORY-CONFORMANCE-0005:** Mirror/retention tests cover incomplete snapshots, lag, corruption/equivocation, failover, privacy/proxy, regional outage, garbage-collection races, legal/security tombstones, backup corruption, restore continuity, and RPO/RTO drills.

**RM-REPOSITORY-CONFORMANCE-0006:** Advisory tests cover exact ecosystem version/source/artifact ranges, architecture/configuration differences, aliases/duplicates, not-affected rationale, under-investigation/fixed/regressed states, severity schemes, remediation applicability, signed revisions, conversion loss, and withdrawal.

**RM-REPOSITORY-CONFORMANCE-0007:** Disclosure tests cover hostile reports/attachments, duplicate/upstream cases, permissions/embargo leaks, private CI/package metadata, reporter communication, coordinated release failure, active exploitation escalation, accessible communications, and retention/redaction.

**RM-REPOSITORY-CONFORMANCE-0008:** Emergency exercises compromise each identity/key/workflow/release/mirror/metadata role and prove declaration, containment, monotonic revocation/root rotation, client propagation, safe replacement, staged recovery, communications, evidence preservation, and post-incident review.

**RM-REPOSITORY-CONFORMANCE-0009:** Cross-ecosystem fixtures cover GitHub releases/attestations/advisories, crates.io publish/yank/ownership, OCI digest/tag/referrers, secure-update metadata, and OSV/CSAF/CVE projections without claiming identical semantics.
